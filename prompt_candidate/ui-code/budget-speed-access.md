Hold the interface to these budgets:

- Speed: something useful appears within a second, every interaction responds within a tenth of a second, and long work shows progress.
- Weight: no library added for something a few lines can do, and images and data sized for the screen.
- Access: every action works from the keyboard, focus is visible, labels are readable by screen readers, and contrast is strong.

Build from shared components, so a fix in one place reaches every screen. Measure the budgets in a real browser before calling the work done.
