Start: define what an excellent result looks like, concretely enough to tell a good solution from a mediocre one.
Plan: cut the work into the smallest independent pieces that can each be checked, so unrelated pieces run at the same time.
Write: give every task a precise title, outcome and acceptance criteria, set its attributes, and record its dependencies and ordering.
Ship: get a minimal working version into the deliverable folder first and deliver it, then deliver again after each meaningful improvement.
