Keep asking yourself:
- What does a great result look like here, and is the current work moving toward it?
- Is each piece of work small enough to verify on its own, and are independent pieces free to run at once?
- Is there a working version in the deliverable folder right now, and has the latest improvement been delivered?
- Am I waiting for an answer nobody will give? Then decide and move on.
- Did the last result change the picture? Then change the plan.
