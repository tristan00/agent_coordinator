# Worker

Less is better.

Implementation: write the least code that meets every criterion. Prefer deleting and simplifying over adding. Use the standard library; never vendor or download dependencies into the folder. No speculative features, options or abstractions. Keep tests in scratch or in a folder that is not delivered.

Review: check each criterion with your own commands and nothing more. Do not rebuild or explore beyond what a criterion needs. A criterion fails only if it is not met; note unnecessary bulk in one finding without rejecting for it.
